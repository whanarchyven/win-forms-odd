# KioskStand — интерактивный стенд «Клинические задачи»

Полноэкранное WPF-приложение для сенсорного стенда (Windows 10/11, .NET Framework 4.8 — уже есть в системе, ничего ставить не нужно).

**Сценарий:** Старт → «Начать» → условие задачи → вопросы (с подсветкой правильных ответов) → … следующая задача … → «Вы прошли обе клинические задачи» → форма регистрации → финальный экран с QR-кодами → «Завершить» → снова старт.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `KioskStand-Catalysis/` | готовый стенд Catalysis (задача Blue Cap): `KioskStand.exe`, `config.json`, `assets/` |
| `KioskStand-Dermedic/` | готовый стенд Dermedic (2 задачи: розацеа, мелазма) |
| `src/` | общий исходный код приложения |
| `build.bat` | сборка `KioskStand.exe` и копирование его в обе папки стендов |
| `dermedic/`, `тачпад/`, `*.png`, `*.docx`, `tz.md` | исходные материалы: ТЗ, макеты, задачи |

На стенд копируется **одна папка** `KioskStand-…` целиком. Exe одинаковый, отличаются только `config.json` и `assets/`.

В каждой папке стенда:

| Файл | Назначение |
|---|---|
| `config.json` | **вся настройка**: задачи, тексты, логотипы, специализации, ссылки и QR, цвета, фон |
| `assets/` | фон, логотипы (`logo_drsarha.png`, `logo_dermedic.png`, `divider.png`), шрифты Inter, персонажи (`decor/`), картинки к задачам |
| `results.json` | создаётся автоматически: прохождения и анкеты (в git не попадает) |
| `exports/` | выгрузки Excel из панели организатора (в git не попадает) |

### Логотипы в шапке

Логотипы задаются в `app.header` (координаты в пикселях холста 2560×1440). Пара «Dr.Sarha | Dermedic»:

```json
"header": [
  { "image": "assets/logo_drsarha.png",  "x": 959,  "y": 93 },
  { "image": "assets/divider.png",       "x": 1236, "y": 86 },
  { "image": "assets/logo_dermedic.png", "x": 1283, "y": 87 }
]
```

Чтобы добавить второй логотип рядом с Dr.Sarha, положите PNG с прозрачным фоном в `assets/` и допишите его в этот массив.

## Панель организатора

Открывается **5 быстрыми касаниями в левом верхнем углу экрана** (или `Ctrl+Shift+A` с клавиатуры) → PIN (`app.adminPin`, по умолчанию `2580`).

Там можно закрыть/открыть регистрацию, провести розыгрыш (`winnersCount` победителей, если участников меньше — побеждают все), посмотреть победителей, выгрузить всё в Excel (листы «Участники», «Победители», «Ответы»), открыть папку с данными и выйти из программы.

## Структура config.json

```jsonc
{
  "app": {
    "fullscreen": true,            // false — оконный режим для отладки
    "topmost": false,              // поверх всех окон
    "hideCursor": false,           // скрыть курсор мыши
    "designWidth": 2560,           // «холст» макета; всё масштабируется под экран
    "designHeight": 1440,
    "background": "assets/background.png",
    "fontFamily": "assets/fonts/#Inter",   // шрифт из папки (или системный: "Segoe UI")
    "header": [],                  // картинки поверх всех экранов: { "image", "x", "y", "width"?, "height"? }
    "idleTimeoutSeconds": 180,     // возврат на старт при бездействии (0 — выключить)
    "adminPin": "2580",
    "resultsFile": "results.json",
    "showCorrectAnswers": true,    // подсвечивать правильные/неправильные ответы после «Ответить»
    "showScore": true,             // показывать «Правильных ответов: X из Y»
    "onScreenKeyboard": true,      // встроенная экранная клавиатура
    "winnersCount": 25
  },

  "colors": {
    "primary": "#EA5A07",         // кнопки, рамки, иконки
    "text": "#EA5A07",            // заголовки, подписи
    "bodyText": "#2B2B2B",        // длинный текст условия и вариантов ответа
    "accent": "#FDE4D5",          // фон выбранного варианта/чипса
    "selectedText": "#000000",    // текст выбранного чипса
    "soft": "#FEF4EE",            // подсветка в списке, служебные клавиши
    "fieldBackground": "#FFFFFF", // заливка полей и кнопок-контуров
    "placeholder": "#F7BD9C",
    "card": "#F2FFFFFF",          // карточка условия задачи (ARGB)
    "overlay": "#80000000",       // затемнение под всплывающими окнами
    "correct": "#1E9E5A", "wrong": "#D64545"
  },

  "decor": {                       // картинки на конкретных экранах:
                                   // start, case, question, done, form, final
    "done":  [ { "image": "assets/decor/doctor_cheer.png", "x": 135, "y": 826 } ],
    "final": [ { "image": "assets/decor/doctor_phone.png", "x": 0, "y": 214 } ]
  },

  "texts": {                       // любые надписи; **жирный**, \n — перенос строки
    "final.note": "**Результаты** розыгрыша опубликуем ... **в 15:00**"
    // полный список ключей — в поставляемом config.json
  },

  "tasks": [                       // МАССИВ ЗАДАЧ — проходятся по порядку
    {
      "id": "bluecap",             // идентификатор (для результатов и Excel)
      "title": "Рецидивирующее шелушение кожи головы",
      "subtitle": "Пациентка М., 26 лет",
      "sections": [                // блоки условия
        { "title": "Жалобы", "text": "..." }
      ],
      "images": ["assets/tasks/bluecap_1.jpg", "assets/tasks/bluecap_2.png"],
      "questions": [
        {
          "id": "q1",
          "text": "Какой диагноз наиболее вероятен?",
          "multiple": false,       // true — несколько правильных ответов
          "options": ["Вариант А", "Вариант Б", "Вариант В"],   // буквы А, Б, В… ставятся автоматически
          "correct": [0],          // индексы правильных вариантов, с нуля (А=0, Б=1, …)
          "hint": "…",             // необязательно: своя подсказка под вопросом
          "explanation": "…"       // необязательно: пояснение после ответа
        }
      ]
    }
  ],

  "registration": {
    "specializations": ["дерматовенерология", "педиатрия", "...", "другое"],
    "otherOption": "другое",       // при выборе появляется поле «Укажите специализацию»
    "cooperationFormats": ["Выступить с докладом на конференции или вебинаре", "..."]
  },

  "final": {
    "linksPadding": 140,           // расстояние между QR-кодами в ряду
    "qrSize": 350,                 // размер QR-кода
    "links": [                     // QR генерируется из url; либо своя картинка в qrImage
      { "label": "MAX", "url": "https://max.ru/...", "qrImage": null },
      { "label": "Telegram", "url": "https://t.me/...", "qrImage": "assets/qr_tg.png" }
    ]
  }
}
```

В файле допускаются комментарии `//` и висячие запятые. Если в конфиге ошибка — при запуске появится сообщение с номером строки.

## Структура results.json

```jsonc
{
  "registrationOpen": true,
  "drawAt": "2026-11-16 15:00:00",            // после розыгрыша
  "sessions": [                               // каждое прохождение задач (в т.ч. без регистрации)
    { "id": "dbe24d35a8", "startedAt": "...", "finishedAt": "...", "correct": 5, "total": 7,
      "tasks": [ { "taskId": "bluecap", "title": "...",
                   "answers": [ { "questionId": "q1", "selected": [0], "letters": "А",
                                  "selectedText": ["..."], "isCorrect": true } ] } ] }
  ],
  "participants": [                           // анкеты
    { "id": "...", "registeredAt": "...", "sessionId": "dbe24d35a8", "score": "5 из 7",
      "fullName": "Иванов Иван", "phone": "+7 (912) 345-67-89", "phoneNormalized": "79123456789",
      "email": "ivan@mail.ru", "specialization": "другое", "specializationOther": "Аллергология",
      "cooperation": "Да", "cooperationFormats": ["Провести семинар или мастер-класс"], "winner": false }
  ]
}
```

Повторная регистрация с тем же номером (сравнение по `phoneNormalized`, 8… и +7… считаются одним номером) не создаёт дубль — участник видит сообщение. Запись атомарная: при сбое сохранения анкета не теряется, введённые данные остаются в форме.
